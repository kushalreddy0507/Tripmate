# 🧭 TripMate — Plan Your Next Adventure

> **Discover India with Live Transit, Dynamic Budget Adjuster, Nightlife Hubs & Stays.**
> Verified database of 900+ Sightseeing Attractions, 940+ Nightclubs & Pubs, and 1,400+ Accommodations across all 218 cities in 35 States & UTs.

---

## ✨ Features

- **🌆 All-India City Coverage**: Explore 218 cities across 35 States & Union Territories.
- **🏛️ 900+ Sightseeing Spots**: Verified timings, entry fees, Google review ratings, DSLR & airport accessibility.
- **🎉 940+ Party & Nightlife Venues**: Nightclubs, rooftop lounges, beach shacks, and craft microbreweries with cover charges, music genres, and vibes.
- **🏨 1,400+ Stays & Accommodations**: Filter by type — *Airbnbs, Solo Backpacker Rooms, Luxury Villas with Private Pools, Homestays, and 5-Star Resorts*.
- **🎚️ Dynamic Budget Adjuster**: Real-time slider (₹500 to ₹25,000+) that filters attractions, cover charges, and stay prices simultaneously.
- **🚗 Live Transit & Cost Engine**: Haversine distance calculations across Car, Bike, Bus, Train, and Flight with estimated hours and travel costs.
- **🔐 Auth & AI Bot OTP Simulation**: Multi-step signup/login with 6-digit verification code, 5-minute expiry, and profile persistence.
- **🌓 Dual Theme Engine**: Sunset Horizon (warm daylight) and Midnight Luxury (dark mode).

## 🚀 Instant Deployment (Free Online URL)

### Option 1: GitHub Pages (Automatic updates on `git push`)
1. Create a new repository on [GitHub](https://github.com/new) named `tripmate`.
2. Push your code:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of TripMate"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/tripmate.git
   git push -u origin main
   ```
3. Go to **Settings > Pages > Branch: main** and click **Save**.
4. Your site is live at: `https://YOUR_USERNAME.github.io/tripmate/`

### Option 2: Vercel (Fastest 1-Click Deployment)
1. Sign in at [Vercel](https://vercel.com) with GitHub.
2. Click **Add New > Project**, select your `tripmate` repo, and click **Deploy**.
3. Live instantly at: `https://tripmate-india.vercel.app` (updates automatically on every commit!).

### Option 3: Netlify
1. Sign in at [Netlify](https://www.netlify.com).
2. Drag & drop the project folder or connect your GitHub repository.
3. Live instantly at: `https://tripmate.netlify.app`.
